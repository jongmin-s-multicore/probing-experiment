## 1. 한 문단 요약

004 의 depth_r2.csv 만으로 세 가지 재집계를 했다: (A) 학습 모델 대비 random-init 의 차이 Δ 곡선에 0.2 하락 규칙 적용, (B) split 별 R² 대신 MAE/MSE/공통 라벨 분산 R² 로 척도 통일, (C) 겹침 검정을 학습 시드 3개 단위로 재계산. 사전 기준대로 저장된 상태는 모두 "관측 안 됨"(A 인코더, A predictor, B)이고 C 는 predictor 가 "관측 안 됨", 인코더가 "계산 불가"이다(`rj`, `log`). **이는 004 의 "소실 없음"을 추가로 지지하는 증거가 아니다.** 세 분석가는 계산 오류가 없고(stats 는 독립 구현으로 재현, B 의 자기검증 최대 차이 8.2e-15) 이 점에 일치하지만, 같은 방향으로 이 "관측 안 됨"의 정보량이 작다고 본다. predictor 의 Δ 는 최대 0.0484 라 0.2 하락이 구조적으로 도달 불가능하고, 공통 분산 R² 는 train/interp 에서 천장에 가까워 0.2 하락이 거의 불가능하다. 새로 확인된 것은 계산 사실 두 가지다. 공통 척도로 보면 interp 의 낮은 split R² 는 분모 효과로 보이고(MAE 가 train 과 비슷), extrap 은 MSE 로 train 의 약 5~6배 나쁜데 split R² 에서는 train 과 같아 보인다. 이는 004 리뷰가 이미 지적한 `ind_ood_gap` 해석 불가를 수치로 다시 확인한 것이다. 갈린 곳은 주로 해석의 수준(Δ<0 의 의미, 학습 기여의 인과, random-init 통제의 성격)이고, 근본 구조 문제(규칙 검정력 부재)에는 일치한다. 004 의 약점인 "검정에 검정력/특이성이 없다"는 008 로 해소되지 않았으며 009(양성 대조, 미실행)가 그 직접 방법이다. 확신 수준: 수치와 구조적 지적(천장, 분모 의존)은 높음, 해석과 문헌 연결은 낮음~중간, 분석가별 전체 확신도는 prior 중간, stats 중간, skeptic 중간~높음.

## 5. 분석가 의견 종합

세 분석가는 서로의 파일을 읽지 않고 독립 작성했다.

### 5.1 세 명이 일치한 점

1. **계산은 정확하다.** prior(results.json 직접 확인, 셀프체크 통과), stats(독립 구현으로 1e-15~1e-16 수준 재현), skeptic(버그 못 찾음, B 자기검증을 "강한 검증"으로 평가).
2. **A 의 predictor 판정은 정보가 없다(천장).** predictor Δ 최고값이 train 0.0248, interp 0.0484, extrap 약 0 이라 0.2 하락이 구조적으로 도달 불가능하다. prior 2.1-3, stats 2절("검정력 0"), skeptic F1. 세 명 모두 이를 "소실 없음의 추가 증거"로 읽으면 안 된다고 한다.
3. **B 도 train/interp 에서 검출 문턱이 높다.** 공통 R² 는 0.95 안팎으로 천장에 가깝다. prior 2.2-2, stats 3절, skeptic F1. (표현 차이: prior 는 "소실에 둔감", stats 는 "도달 불가능성의 영향", skeptic 은 "문턱이 약 3~10배 높아짐(추정)".)
4. **split R² 는 분모(라벨 분산) 의존이다.** 공통 척도에서 interp 가 train 과 같거나 더 낫고(MAE 0.111 대 0.114), extrap 은 MSE 로 약 5~6배 나쁘지만 split R² 로는 train 과 같아 보인다. 004 의 `ind_ood_gap` 과 겹침은 이 인공물에 영향받는다. prior 2.2-1, stats 3절, skeptic F2.
5. **C 의 extrap 변화(4/7 -> 5/7)는 한 깊이 차이이고 불안정하다.** 학습 시드 3개(df=2), 경계 근처. prior 2.3, stats 4절, skeptic F2.
6. **인코더의 불확실성 단위는 네트워크 변동이 아니다.** 학습 시드가 없고 probe seed 의 sd 는 거의 0 이다(A 인코더 보조 판정 7/7 은 정보가 약하다). prior 2.1, stats 2절, skeptic I1.
7. **008 은 004 판정을 바꾸지도 강화하지도 못한다.** 사후 탐색이고 비보정이며 004 의 검정력 문제를 다루지 않았다. prior 1, 6절, stats 5절, skeptic "004 판정과의 관계". 해소 수단으로 009(양성 대조)를 지목하는 점도 일치(prior 5절 H-post-2, stats 6절 5, skeptic 추가 실험 2).
8. **B 에서 시드 sd/CI 를 내지 않았고, 척도 통일(B)과 시드 단위 재계산(C)을 결합하지 않았다.** stats 3절은 sd 부재를, skeptic I3 는 결합 부재를 지적했다. prior 는 이 둘을 직접 지적하지 않았다(아래 5.3 참조).

### 5.3 한 명만 지적한 점

- prior 만:
  - 문헌 정합(Raghu 2021 초록 수준, Hewitt & Liang 2019 요약 수준 확인; Zhang & Bowman 2018, Lakens 2017 등은 미확인; papers/ 비어 있고 이번 세션에 새로 읽은 문헌 없음). 리포터는 문헌을 근거로 쓰지 않았다.
  - 빠진 대조로 **항등 predictor 의 깊이별 곡선**(Δ extrap<0 이 "학습이 z 를 덜 보존"인지 "random-init 블록이 우연히 z 를 더 보존"인지 구분), 크기와 무관한 속성(그리퍼 위치 등)의 깊이별 곡선(4절).
  - 후보 사후 가설 H-post-1(학습 predictor 가 InD 크기 판독성을 약간 올리고 OoD 에서는 올리지 못함; 새 학습 시드 ≥5 와 사전 동등성 여유 필요, 추정), H-post-3(gap(d) - gap(0) 지표를 기존 CSV 로 CPU 계산)(5절).
  - 인코더 interp 의 공통 R² 가 깊이와 함께 거의 단조 증가한다는 관찰과 extrap 의 큰 MAE 의 회귀 외삽 shrinkage 설명(추정)(2.2-3, 2.2-4).
- stats 만:
  - 불확실성 단위 혼재: 인코더는 n=1 네트워크, predictor 는 df=2(표본 sd 의 참값 대비 95% 구간 [0.52, 6.28]). 두 모듈의 Δ>0 을 한 표에서 비교하면 안 된다(2절).
  - 평균 - 2sd 규칙이 n=3 에서 t > 3.46 과 같고, 21 검정에 Bonferroni 단측 95% 라면 t > 14.44 가 필요하다(2절).
  - 임계 0.2 의 MSE 환산이 split 간 약 20배 불균일(위 4.3), 라벨 군집 수가 적음(pseudo-replication).
  - 권고: 규칙의 도달 가능성 점검 표기("Δ 최대폭 < 임계면 검정력 없음"), InD/OoD 는 MAE 또는 공통 R² 를 주 지표로(6절).
- skeptic 만:
  - **F2**: C 에서 004 대비 변화의 계수 설명(sqrt(10/14) = 0.845), probe seed 가 복제본이라는 지적(인코더 CSV 2-14행과 15-27행이 같은 값).
  - **I4**: "결과 전 기준"의 지위가 약하다. 008 의 원 곡선이 이미 공개된 상태였고(A predictor, B 의 결과는 예측 가능), hypotheses.md 가 git 에서 수정 상태(M)라 기준을 적은 시각과 실행 시각의 선후를 이력으로 확인할 수 없다.
  - **S3-S6**: B 자기검증이 predictor/real 조합 하나만 확인, `json.dumps(default=lambda o: None)` 가 직렬화 실패를 조용히 null 로 바꿈, 쓰지 않는 코드(run.py 135-137행), 인코더 probe seed 의 sd 가 depth 0, 6, 10 에서 정확히 0 인 패턴(CV fold 에만 작용한다는 추정). 실험명이 "004_005" 이나 005 계산도 캐시 사용도 없다.
  - 추가 실험 3개(공통 척도 InD/OoD 겹침 CPU, 009 에 A/B 규칙 결합, 라벨 셔플 대비 Δ 와 잔차 제거 random-init 의 영 분포 통제).

4. **009 (양성 대조, 004 파이프라인의 검정력)**: 008 후속 중 가장 직접적이다. 세 분석가가 모두 004/008 의 핵심 약점(규칙의 검정력 부재)의 해결책으로 지목한다(5.1-7). 개입 predictor 에 004 의 규칙을 적용해, 강도 1.0 에서도 소실이 검출되지 않으면 004 의 refuted 를 검정력 없는 결과로 표시한다(hypotheses.md 376행). skeptic 은 여기에 008 의 A(Δ 곡선)와 B(공통 R² 0.2) 규칙도 같이 적용해, 강도 1.0 에서도 "관측 안 됨"이면 008 의 A/B 를 검정력 없는 규칙으로 표시하자고 제안했다(추가 실험 2). 이는 009 의 현재 초안(004 규칙만)에는 없는 확장이며 사람 결정 사항이다(8절 2번). 009 selftest 는 toy 에서 부분 강도(0.5)가 크기 성분을 축소만 해 다시 학습한 linear probe 의 R² 가 기준선과 같았다고 기록했다(log.md 247행). 이는 부분 강도가 재학습 probe 로는 검출되지 않을 수 있다는 단서이며, 해석은 하지 않는다.
5. **010 (원천 분리 대조)**: 005 의 ours ≈ random 이 인코더 표현 때문인지 predictor 때문인지 가른다. 008 은 005 계산을 하지 않았으므로(skeptic S5) 010 과 직접 겹치지 않는다. 다만 008 의 A(predictor Δ 가 작음, random-init 이 통과 통제처럼 거동)는 ours≈random 의 해석과 같은 맥락이다. 010 의 판정은 TOST(Δ 제안값 0.05, 승인 대기)이므로 stats 의 동등 여유 권고(6절 3)와 같은 방향이지만, 004 겹침 규칙의 재정의는 아니다.
6. **빠진 대조(prior)**: 항등 predictor 깊이별 곡선, 크기와 무관한 속성의 깊이별 곡선. 004 보고서 7절 6번과 겹친다.
7. **관계 정리(리포터 정리, 분석가 합의 아님)**: 1번은 CPU 만 쓰는 제안이고 4번(009)이 검정력 문제를 직접 다룬다. 둘의 실행 순서는 분석가가 정하지 않았으며 사람 결정 사항이다.
