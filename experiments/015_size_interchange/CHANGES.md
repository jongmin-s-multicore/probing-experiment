3. 레벨 평균 m_L: 013 `level_means` 규칙(학습 레벨의 train split episode 전부, 입력 프레임 0..11, 패치 위치별)과 같고 selftest 에서 013 함수 결과와 일치함을 확인. 레벨별 실제 움직임 DZ_L 은 같은 episode 의 12 전이 평균 z_{t+1} − z_t(패치 x 384). d = DZ_T − DZ_S. 모두 Q1 캐시(`tokens_dino`, fp16)에서 계산하고 float64 로 평균(episode 당 평균은 float32 로 보관).
4. 관문(split-half cosine) [사용자 결정 2026-11-12: 변경 반영함]: 관문 값 = **무작위 50/50 분할 20회(RandomState(seed + 1), 레벨 순서대로 뽑음)에서 d 의 split-half cosine 을 구해 평균**한 값 ≥ 0.5(임계값 그대로, config `gate.d_reliability: {min: 0.5, aggregation: mean_over_splits, n_splits: 20}`). 이전 구현은 한 번의 분할(RandomState(seed))만 썼다. 한 번의 분할 cosine 은 보고용 진단(`d_split_half_cosine_single_split`)으로 남기고, 20회 평균/표준편차/최솟값은 `d_split_half_cosine_mean20/sd20/min20`. 어느 분할이 nan 이면 평균이 nan 이라 통과하지 못한다. 관문 cosine 은 S>T 와 T>S 에서 비트까지 같으므로(부호만 뒤집힘) 두 방향이 항상 함께 통과/탈락한다(selftest 로 확인).
5. 가짜 교체 [사용자 결정 2026-11-12: 주 비교값을 크기를 맞춘 것으로 변경 반영함]: 재스케일 전(unscaled) shift 는 그대로다: S 레벨 train episode 100개의 episode 별 평균 잠재를 무작위 순열로 반반 나누고 shift = 앞 절반 평균 − 뒤 절반 평균(패치별), 20회, RandomState(15000) 하나로 레벨 순서 x 반복 순서대로 추첨(추첨 변경 없음). **쌍(S,T)마다 이 20개를 패치별로 fake[p] × |m_T[p] − m_S[p]| / |fake[p]| 로 재스케일한 것(`fake_normmatched`)이 판정의 주 비교값**이다(episode 별로 20회 반복의 moved 평균). 쌍별이라 두 목표 T 가 순전파를 공유할 수 없다. 보호 장치(내가 정한 선택, 확인 필요): |fake[p]| ≤ 1e-12(float64)인 패치는 재스케일할 수 없어 shift 를 0 으로 두고(그 패치는 norm 불일치), 그 개수를 `fake_normmatched_n_guarded_patches` 에 기록한다(기대값 0). |m_T[p] − m_S[p]| = 0 이면 shift 0(정확히 일치). 재스케일 전 가짜 교체는 보고만(`fake_unscaled_*`, `diff_unscaled`). fit.json: `fake_unscaled_over_real_frob`, `fake_unscaled_shift_*`, `fake_normmatched_shift_*`(= 실제 shift norm), 복사통과 진단 `copy_through_fake_unscaled_mean/sd`, `copy_through_fake_normmatched_mean/sd`. 한계: 크기를 맞춘 가짜 shift 는 방향이 표집 잡음이라 방향 구조(예: 레벨 평균의 큰 성분)까지 맞춘 것은 아니다. 가짜 shift 의 부호는 앞 절반 − 뒤 절반으로 임의.
6. 무작위 방향(보고만) [사람 확인 필요]: 013 `random_dirs(20, 384, 13000)` 의 단위 방향 k 를 쓰고 shift[p] = |m_T[p] − m_S[p]| x 방향 k (모든 패치에 같은 방향, 패치별 norm 일치, 부호 무작위화 없음). 013 의 level_mean_match 대조(패치별 무작위 부호)와 다르다. 방향 20개는 모든 쌍에서 같다.
7. moved 의 구현: Δ̂(x) = pred(x) − x, moved = ((pred(z') − pred(z)) − shift)·d/|d|² (패치 x 384 를 펴서 내적). 전이마다 계산하고 episode 당 12 전이 평균. **Δ̂ 를 편집된 입력 기준으로 잡았으므로 입력을 그대로 복사하는 predictor 는 moved = 0 이 정확히 나온다**(selftest 로 확인). 입력과 무관하게 고정 출력을 내는 predictor 는 moved = −(복사통과 진단값)이 된다(selftest 로 확인). 복사통과 진단값 (m_T − m_S)·d/|d|² 는 fit.json 에 쌍별로, 가짜 교체의 같은 값(평균/표준편차)도 기록.
8. 평가 episode: 원천 레벨 S 의 test split episode(레벨당 100). 파일럿(`--episodes-per-level N`)은 레벨별 rank_in_level 앞 N 개. 학습 레벨 3개 외의 레벨(OoD 6개)은 평가하지 않는다. 한 번의 순전파 묶음에서 편집 없는 예측 pred(z) 와 재스케일 전 가짜 20개는 S 마다 한 번만 계산해 두 목표 T 에 재사용(결과는 쌍마다 따로 계산한 것과 같음). S 당 순전파 수 = 1 + 20 재스케일 전 가짜(두 목표 공유) + 2 x (1 실제 + 20 크기를 맞춘 가짜 + 20 무작위) = 103(이전 63). 크기를 맞춘 가짜는 쌍별이라 공유하지 못한다. 편집 없는 예측과 재스케일 전 가짜 20개만 두 목표 T 에 재사용.
