## 0. 요약

1. 학습 크기 분포와 외삽: 정상 추출된 단일 크기 학습 5개(single_a026 s0, s2 / single_a248 s0, s1, s2)는 모두 학습 크기 쪽으로 이동했다. 이는 Kang 2024 의 "분포 밖에서는 학습 분포의 상수(OCS)로 회귀"와 방향이 같다(설정이 달라 같은 현상이라고는 쓸 수 없고, 방향이 맞는 선행 사례까지). H-H1 의 not_evaluable 은 c(비가 1 을 가로지르는 크기)가 끝 크기 학습에서 구조적으로 정의되지 않는 경우가 있기 때문이며(a248 s0, s1 은 전 크기 비>1), 반증이 아니라 지표 설계의 한계다.
2. mix_wide 가 mix_adjacent 보다 크기 보존이 낫다는 것은 "지원이 넓을수록 외삽 거리가 줄어든다"는 직관과 방향이 같다. 그러나 (a) mix_adjacent 는 s0 이 측정 실패라 유효 2시드, (b) 9점 기울기는 지원 안 크기 개수에 지배되어(mix_wide 6점 대 mix_adjacent 3점) "혼합 효과"와 "지원 폭 효과"가 분리되지 않고, (c) baseline 이 다른 환경(001)의 값이다. 또 single_a248(0.53~0.58)이 mix_adjacent(0.42~0.50)보다 기울기가 높아 "섞으면 오른다"는 일반 원리로 읽을 수 없다.
3. 디코더 붕괴는 잠재 예측과 분리해서 볼 수 있다. 두 붕괴 run 의 `val_z_visual_err_pred` 는 형제 시드 범위 안이다(2절 수치). 같은 설정에서 디코더 상수 붕괴를 보고한 문헌은 찾지 못했다(미확인). 일반 후보 원인은 Adam 손실 스파이크, 죽은 뉴런 등이며 모두 추정이다.
4. 픽셀 면적 지표는 디코더 + HSV 마스크를 거치므로 디코더 실패가 면적 0 으로 나타나고, 학습 크기 밖 latent 에서는 디코더 자체가 분포 밖이다. 003 은 학습된 디코더별 GT-latent 재구성비를 추출하지 않아 predictor 편향과 디코더 오독을 분리할 수 없다.

### 1.2 문헌과의 대응

- 상수 회귀(OCS): Kang et al. 2024 ("Deep Neural Networks Tend To Extrapolate Predictably", ICLR 2024, arXiv 2310.00873; 웹 요약 확인)는 분포 밖으로 갈수록 출력이 입력과 무관한 상수, 대개 학습 분포에서의 최적 상수 해로 이동한다고 보고한다. 그쪽은 단발 예측, 이쪽은 12 스텝 자기회귀 + 디코더 + 마스크라 조건이 다르다(추정: 같은 기제라는 증거는 아님).
  - 단일 크기 학습의 OCS 는 그 크기이므로 H-H1 예측과 같은 방향이다. single_a026 기울기 0.002 / 0.145 는 거의 상수 면적 출력에 해당하고 001(ind, 0.15~0.31)보다 더 상수적이다.
  - single_a248 은 0.53~0.58 로 상수성이 훨씬 약하다. a026 과 a248 의 비대칭은 이 실험으로 설명되지 않는다. 후보(추정, 미검증): (i) 큰 천은 프레임 내 정보량이 많아 같은 거리의 외삽에서도 크기 신호가 덜 지워진다, (ii) 면적 지표의 하한 비대칭(`max(area,1)`, 접힘으로 인한 면적 감소), (iii) 디코더가 학습한 크기 분포 차이(3절).
  - 혼합 학습의 OCS 는 혼합 분포 평균 쪽이어야 하나, 평균비가 1 을 가로지르는 c(1.1~1.6)는 "에피소드별 비의 평균"이 분모가 작은 에피소드로 부풀려져 있어(001 보고서 정정 4) 해석에 의미를 두기 어렵다.
- 지원 폭과 외삽: Xu et al. 2021 (ICLR, arXiv 2009.11848; 요약 확인)은 ReLU MLP 가 학습 지원 밖에서 방향별로 선형 수렴해 비선형 목표를 외삽하지 못한다고 보인다(NTK 가정). Balestriero, Pesenti, LeCun 2021 (arXiv 2110.09485; 요약 확인)은 고차원에서 새 표본이 학습 데이터의 볼록껍질 안에 드는 경우가 거의 없다고 논한다. 둘 다 "지원이 넓을수록 외삽 성능이 낫다"를 이 설정에서 직접 검증한 것은 아니다. 크기 라벨 축에서의 "지원 안"이 잠재 공간에서도 "안"인지는 불확실하다(Balestriero 의 논점, 추정). 그래도 실측에서 mix_wide 의 지원 안 기울기(0.77~1.07)가 지원 밖(0.63~0.73)보다 높아 크기 축 지원 개념은 이 데이터에서 유효해 보인다.
- mix_wide 가 mix_adjacent 보다 낫다는 점은 방향이 문헌 직관과 맞으나 약한 증거다.
  1. mix_adjacent 는 s0 이 측정 실패라 유효 쌍이 s1, s2 뿐이다.
  2. 9점 기울기는 지원 안 크기 개수에 지배된다(mix_wide 6/9, mix_adjacent 3/9). 지원 안 점이 많으면 9점 기울기가 오르는 것은 지표 구성 효과일 수 있다. 분리하려면 같은 크기 집합의 부분 기울기로 baseline 과 비교해야 하는데 baseline 의 부분 기울기는 001 에서 계산되지 않았다(README 5번).
  3. baseline 은 다른 실험, 다른 환경이다(4.1).
- 단일 크기가 인접 혼합보다 기울기가 높다: single_a248(0.53~0.58) > mix_adjacent(0.42~0.50). "크기를 섞으면 기울기가 오른다"가 아니라 이 9점 기울기가 학습 크기의 위치(끝/가운데)에 민감하다는 관측이다. 이 지표를 수축 정도의 일반 지표로 쓰는 것은 위험하다.
- H-H2 산술: mix_wide 최솟값 0.6508 - baseline 최댓값 0.3102 = 0.340 이므로 9쌍 모두 0.2 이상. mix_adjacent 는 s1 0.5023 - 0.3102 = 0.192, s2 0.4153 - 0.3102 = 0.105 로 정상 2시드만 보아도 pass 가 아니고(baseline s2 0.150 대비는 0.352, 0.265) fail 도 아니다. 이 규칙은 baseline 시드 범위(0.15~0.31) 때문에 mixed 가 나오기 쉬운 구조다(README 4번 지적이 맞음). 따라서 mix_adjacent 의 not_evaluable 은 측정 실패뿐 아니라 규칙 때문에도 남는다.

### 1.3 문헌 일치 여부

- 단일 크기 학습의 학습 크기 쪽 끌림: 방향 일치(Kang 2024). 크기는 시드·크기별 변동이 크다(a248 에서 a026 비 10.7~15.9). 중간 확신.
- 넓은 지원이 더 낫다: 방향은 직관과 일치하나 이 실험이 검증한다고 보기 어렵다(교란 3가지). 낮은~중간 확신.
- 월드 모델에서 객체 크기 분포와 크기 보존을 직접 다룬 보고는 확인하지 못했다(미확인).

## 2. 디코더의 학습 중 상수 출력 붕괴와 잠재 예측 품질의 분리

### 2.1 사실 (decoder_recon_by_epoch.json, results.json, 이미지)

- exp003_mix_adjacent_s0: `val_img_mse_reconstructed` 가 epoch 2 에서 0.00296, epoch 3 에서 0.0787, 이후 0.0785~0.0787 에서 정체(epoch 15: 0.07856). `train_img_mse_reconstructed` 는 epoch 3 에서 0.00217 로 정상, epoch 4 에서 0.0729 로 상승 후 0.0728 근처. 검증은 epoch 3 평가 시점에, 학습 평균은 epoch 4 에 처음 보이므로 붕괴는 epoch 3 도중에 일어난 것으로 보인다(추정).
- exp003_single_a026_s1: epoch 15 val 0.03305, train 0.03394. 같은 분포 형제(s0 0.00119, s2 0.00119)의 약 28배(산술).
- 두 run 의 `train_env`: fresh, `n_resumes` 0, A100, 패치된 train.py. 기록상 재개 때문이라는 가설은 지지되지 않는다. mix_wide 3개는 train_env 기록이 없어 비교 불가.

- 잠재 예측은 붕괴하지 않았다(epoch 15, run 키 순서로 대응): `val_z_visual_err_pred` mix_adjacent s0 0.2062 vs s1 0.1851, s2 0.1815; single_a026 s1 0.1310 vs s0 0.1205, s2 0.1329. `val_z_visual_err_rollout` mix_adjacent s0 0.342 vs s1 0.331, s2 0.400; single_a026 s1 0.230 vs s0 0.181, s2 0.235. mix_adjacent s0 의 pred 는 형제보다 약 12% 높으나 mix_wide 시드 간 범위(0.175~0.196)와 겹친다. 최종 `val_loss` 가 붕괴 run 에서 더 높은 것(0.2658 대 0.189 근처, 0.1608 대 0.127 근처)은 val_loss 에 디코더 항이 포함된다는 추정과 맞지만 코드로 확인하지 못했다.

### 2.2 문헌

- DINO-WM(Zhou et al., ICML 2025, arXiv 2411.04983; 웹 요약)은 다음 잠재 예측을 잠재 공간에서 학습하고 복원 디코더는 따로 학습한다고 알려져 있다(블로그 요약 기준, 원문 대조 필요: 미확인). 이 구조라면 "디코더 붕괴가 잠재 예측을 바꾸지 않는다"는 위 수치와 일관된다. acwm-phys 브랜치가 디코더 손실을 predictor 로 역전파하는지는 코드를 읽지 않아 모른다.
- 디코더/AE 의 학습 중 상수 출력 붕괴를 이 설정에서 보고한 문헌은 찾지 못했다(미확인). 일반 후보(추정): Adam 2차 모멘트로 인한 손실 스파이크("Adaptive Preconditioners Trigger Loss Spikes in Adam", arXiv 2506.04805; 웹 요약 확인, 디코더 붕괴를 직접 다루지는 않음), 죽은 뉴런/포화(Lu et al. 2019 로 기억하나 이번 검색에서 확인 못 함: 미확인). 한 epoch 안에서 급등 후 12 epoch 동안 ±0.0001 안에 고정되는 양상은 회복 불가한 사건(포화, 죽은 뉴런)과 맞고 느린 과적합과 맞지 않는다(추정).
- 발생 빈도: 003 의 patched 9개 중 2개, 002(patched 6개) 0개, 001 3개 0개(001 은 마지막 epoch 지표만 있음), mix_wide(비패치) 3개 0개. 표본이 작아 코드·환경 차이로 귀속할 수 없다.

### 2.3 결론

- 두 붕괴 run 은 디코더·마스크 경로의 측정 실패이며 잠재 예측 품질의 증거가 되지 못한다. 반대로 이 run 의 잠재 오차가 정상이라는 점은, 정상 run 의 크기 편향이 디코더 때문인지 predictor 때문인지 가르는 데 쓸 부수 정보가 된다(제안이지 결과가 아님).
- 붕괴 run 을 빼면 H-H1 single_a026 과 H-H2 mix_adjacent 는 2시드가 된다. 사전 등록의 "3시드 전부"는 충족 불가이므로 not_evaluable 은 규칙상 올바른 출력이다. 재학습 여부는 사람 결정이다.

## 3. DINO-WM 계열에서 픽셀 면적 지표의 한계

- 지표 경로: 예측 latent -> 디코더 -> 224x224 HSV 마스크. `ratio_ol_over_real` 은 predictor 오류, 디코더 오류, 마스크 오검출의 합이다. 001 에서 GT latent 복원비가 a026 에서 0.915~0.974, 에피소드의 26~44% 가 0.9 미만이었다(001 보고서 3.1절). 003 의 단일 크기 학습은 디코더도 그 크기 데이터만 본다. 그 디코더가 다른 크기 GT latent 를 얼마나 복원하는지는 003 이 추출하지 않았다(README: 003 extract 에서 teacher-forced 등을 뺌). 그래서 single_a248 에서 a026 비가 10.7~15.9 인 것이 predictor 의 크기 편향인지 디코더의 분포 밖 오독인지 분리되지 않는다. 가장 큰 누락 대조다.
- 디코더 붕괴가 곧 면적 0: `slope_ol` 이 0.0 으로 저장되고 판정 집계가 이를 측정 실패로 걸러내지 않는다(c 는 "a size has no valid mean ratio"로 null 처리). 측정 실패를 기울기 값으로 저장하는 것은 위험하다. 면적 0 비율이나 표본 프레임 분산 검증이 파이프라인에 없다.
- 평균비 불안정: 에피소드별 비의 평균은 분모가 작은 에피소드로 부풀려진다(001 보고서 정정 4: a026 3.99배 대 평균끼리의 비 2.36). a026 비 10.7~15.9(CI 상한 22.5, 37.9)는 같은 문제의 극단 사례일 가능성이 높다(추정). c 와 CI 판정도 이 지표에 의존한다.
- 후반 프레임 문제: 001 stats 가 지적한 k=12 에서 마스크 면적과 입자 수 상관 저하(001 보고서 5.4절 인용)는 003 에서도 그대로일 것이다(003 에서 재확인 안 함).
- 문헌에서 월드 모델 평가에 픽셀 면적 지표를 쓴 선례는 확인하지 못했다(미확인). 디코더를 거치지 않는 잠재 공간 판독(probe)이 대안이며 002 가 그 방향이었고 003 에는 없다(추정: 문헌 관행에 가깝다).

## 4. 빠진 baseline 과 인용해야 할 선행연구

### 4.1 빠진 baseline / 대조

1. 같은 파이프라인의 ind 단일 baseline. H-H2 baseline 은 001(RTX 5090, torch 2.7.1+cu128, 001 extract)의 값이다. 003 은 Colab A100/L4, torch 2.0.1 계열(CHANGES 기록)과 경량화한 새 extract 로 측정하며 README 도 "001 숫자와 일치하는지 미확인"이라 썼다. 002 single_ind 는 같은 Colab 환경이나 평가 크기 집합이 달라 직접 비교가 안 된다. 003 환경에서 ind 단일을 재학습하거나 003 extract 로 001 체크포인트를 재측정해야 한다. 우선순위 가장 높음.
2. 학습된 디코더별 GT-latent 재구성비(크기별). 12개 모델 모두.
3. 상수 출력 하한과 persistence: "학습 평균 면적 상수 출력"과 "마지막 context 프레임 복사" 대비 기울기. Kang 2024 의 OCS 틀에는 OCS 와의 거리가 필요하다.
4. 지원 폭 통제 비교: 같은 크기 집합에서 baseline 과 같은 기준의 부분 기울기.
5. 가운데 단일 크기 대조(a040, a160 등). 학습 크기 위치 효과와 혼합 효과의 분리(001 보고서 8절 8번과 같은 제안).
6. 시드 수: 3시드(일부 셀 2시드). 사전 등록의 "3시드 전부"와 맞물려 not_evaluable 이 쉽게 나온다.

## 5. 연구 공백과 후보 가설 (제안만, 승인 아님)

공백: (a) 월드 모델의 객체 크기 분포 외삽 직접 보고 없음, (b) DINO-WM 계열에서 디코더/마스크 경로와 predictor 를 분리하는 표준 방법 미확인, (c) 지원 폭과 혼합 효과를 분리하는 통제 실험 없음.

후보 가설(사전 등록 전 초안):
1. H-OCS: 단일 크기 학습의 open-loop 출력 면적은 학습 크기 면적 근처 상수로 수렴한다. 판정은 c 가 아니라 "크기 간 출력 면적 분산 / 학습 크기 출력 면적" 같은 상수성 지표(c 는 끝 크기에서 정의 불가).
2. H-Support: 9점 기울기 차이는 지원 안 크기 수로 설명된다. 같은 크기 집합 부분 기울기로 비교하면 mix_wide 와 baseline 의 차이가 줄어든다(반증 가능).
3. H-Decoder-OOD: 단일 크기로 학습한 디코더는 학습 크기 밖 GT latent 도 면적을 틀리게 복원한다. 003 체크포인트로 크기별 재구성비를 재면 검증 가능(GPU 소량).
4. H-Collapse: 디코더 붕괴는 학습률/초기화 시드에 의존하는 불안정이다. 같은 시드로 재현되는지, train.log 와 optimizer 상태 확인이 먼저.

## 6. 판정과 다르게 읽을 때 주의

- H-H1: single_a248 s0, s1 은 8개 비학습 크기 모두 비>1(CI 가 1 위 제외)이어서 학습 크기 쪽 끌림과 방향이 맞고, c 가 null 인 이유는 "비가 1 을 가로지르지 않음"이다. single_a248 s2 는 c=2.209 로 학습 크기(2.479)에 가깝다. single_a026 s0, s2 는 c 0.34, 0.33 으로 학습 크기에 가깝다. 판정은 not_evaluable 이나 정상 추출 5개의 방향은 같다. 지표 한계를 보여주는 관측이며 규칙을 바꾸자는 제안이 아니다(결과를 본 뒤 규칙을 바꾸면 사후 조정).
- H-H2 mix_wide pass 는 규칙대로 계산된 값이다. 다만 baseline 이 다른 환경(001)이고 mix_wide 는 train_env 기록이 없으며 train.py 가 패치 없는 원본이다(README). 차이가 최소 0.340 으로 커서 환경 차이만으로 설명되기는 어렵다고 추정하나 검증하지 못했다.
- 재개 run(single_a026 s0: L4 epoch 1 후 A100 혼재, single_a248 s2: epoch 1 후 재개 1회)은 중단 없는 run 과 bit 단위로 같지 않다. 두 run 값(기울기 0.0022, 0.5518)이 같은 분포 형제와 크게 다르지 않아 영향은 작아 보이나(추정) 검증하지 못했다.

## 7. 확신도

- 전체: 중간~낮음.
- 높음: 붕괴 두 run 이 측정 실패라는 점(면적 0, 복원 MSE 급등, 표본 이미지 상수가 서로 일치), H-H2 의 산술.
- 중간: 단일 크기 학습의 학습 크기 쪽 끌림이 Kang 2024 와 방향이 맞다는 해석(방향만, 설정 차이가 큼), 붕괴 run 의 잠재 예측이 정상 범위라는 점(run 키 순서 대응과 형제 2~3개 비교에 의존).
- 낮음: mix_wide 가 더 낫다는 문헌 일치 주장(교란 3가지), 디코더 붕괴 원인(Adam 스파이크, 죽은 뉴런 모두 추정, train.log 미확인), a026 과 a248 의 비대칭 설명.
- 이유: 문헌은 웹 요약·초록 수준이며 본문을 정독하지 않았다. 셸이 없어 results.json 을 재계산하지 못하고 읽은 구간의 값만 썼다(single_a248 s2 의 CI 플래그 등 일부 미확인). 코드(src/exp003)를 읽지 않아 판정·디코더 손실 구조는 문서 범위로만 판단했다. 시드 3개(일부 2개).
