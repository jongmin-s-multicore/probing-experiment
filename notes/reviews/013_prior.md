## 2. 선행연구와의 정합 검토
문헌 상태 표기: [서지확인] = 이번 또는 이전 세션에서 초록/서지 수준 확인. [미확인] = 기억 기반, 본문 미열람, 인용 전 확인 필요. 이번 세션에서 새로 웹 검색은 하지 않았다.

1. **Amnesic probing (Elazar et al. 2021, arXiv:2006.00995 [서지확인: 이전 세션 검색 요약만])**: 판독 가능성과 사용은 다르며, 정보를 제거(INLP 류)한 뒤 과제 성능 변화로 사용 여부를 본다는 논지로 알고 있다. 013 은 이 논리의 world model 판이다. 구조적 일치점: (i) 제거 후 *행동* 지표를 본다, (ii) 같은 규모의 무작위 제거를 대조로 둔다(amnesic probing 의 대조는 무작위 방향 제거로 기억하나 세부 [미확인]). 013 의 `criterion_not_met` 와 "사용 안 함이 아님" 단서는 이 문헌의 비대칭(제거 실패 시 "사용 안 함" 결론 불가)과 맞는다. 단, amnesic probing 은 제거 후 *제거 성공*을 판독으로 확인한 뒤 해석하는데, 013 의 확인 수치는 블록 1 에서 R² 0.68-0.72 로 소거가 사라진 상태다. 즉 "입력에서만 소거"는 정의상 첫 블록 이후의 사용 경로를 막지 못한다. 이는 문헌과 모순이 아니라 013 이 amnesic 설계를 predictor 입력 한 점에 적용한 결과다(추정).
2. **LEACE (Belrose et al. 2023, arXiv:2306.03819 [서지확인: 초록])**: 선형 분류기가 개념을 검출 못 하게 하는 최소 변경 소거. 보장은 선형 판독기·소거 적합 분포에 한정(초록 수준). 013 의 LEACE 는 스칼라 라벨, 패치 평균 기준으로 적합하고 토큰별로 적용하며(CHANGES 4) 소거 직후 블록 0 에서 선형 R² -0.07 로 보장에 맞게 작동했다. 이후 회복은 012 의 MLP/attentive 잔존, 009 의 회복과 같은 방향의 증거다. LEACE 가 *최소 변경* 이라는 성질은 이 결과 해석에 중요하다: 크기 방향 변위는 데이터 분포 안의 방향이고, 무작위 방향은 분포 밖일 수 있다(아래 3절).
3. **INLP (Ravfogel et al. 2020, arXiv:2004.07667 [서지확인: 초록]) 및 Kumar, Tan, Sharma 2022 (arXiv:2207.04153 [서지확인: 초록])**: 한 번의 선형 투영으로는 개념이 지워지지 않고 반복이 필요하며, 분류기 기반 제거는 개념 검출·제거에 신뢰가 낮다는 취지. 013 은 1회 1방향 소거(INLP 첫 반복에 해당, 추정)라 같은 한계를 가진다. level_mean_match 는 레벨 평균을 맞추므로 3-클래스 평균 공간 전부를 지우는 더 강한 소거지만, 분산·모양 정보는 남는다(README 한계).
4. **Causal abstraction / interchange intervention (Geiger et al. 2021 등) [미확인: 서지·내용 기억 기반]**: 사용 여부를 "반사실 입력의 내부 표현을 바꿔 출력이 추상 인과모델대로 변하는가"로 본다고 기억한다. 013 의 3단계(반사실 짝 교체)가 이에 가장 가깝지만 데이터에 짝이 없어 보류됐다(hypotheses 437행). 따라서 현재 013 은 interchange intervention 이 아니라 **제거(ablation) 기반 필요성 검사**이다. 소거는 "필요하다"를 보일 수는 있어도 "크기 정보가 크기에 따른 동역학 예측에 *충분*하다"를 보이지 못한다(추정). 이 구분(필요 대 충분, 제거 대 교체)은 이 팀 결과 서술에 명시할 가치가 있다.
5. **판독 가능성 대 사용 (Hewitt & Liang 2019 arXiv:1909.03368 [서지확인-요약 이전 세션]; Alain & Bengio 2016, Ravichander et al. 2021, Belinkov 2022 [미확인])**: 013 은 004/006/010 의 "읽을 수 있음"과 009/012 의 "소거해도 읽힘"에서 한 걸음 나아가 사용을 시도한 첫 실험이다. 결과(소거 시 오차 악화가 무작위 대조보다 크지 않음 또는 매우 작음)와 판독 R² 가 소거 후 블록 1 에서 회복하는 사실은 "정보가 읽히지만 이 소거의 입력 변경으로는 사용 경로가 검출되지 않는다"로만 읽을 수 있다.
6. **World model 의 물리 파라미터 사용**: 이번에 새로 조사하지 않았다. 이전 세션 prior 파일(notes/research/analyst-prior.md, prior_phys_param_shift.md)이 있으나 본 리뷰에서 인용 근거를 다시 확인하지 않았다. DINO-WM(Zhou et al.)이 파라미터 변화(질량·마찰 등)에 대한 사용을 amnesic 식으로 검증한 보고는 내가 아는 한 [미확인]이며, "없다"를 단언하지 않는다.

## 3. 결과가 크게 다르거나 해석이 흔들리는 지점 (추정 다수)
- **LEACE motion Δ_use 가 음수(-0.15, 모든 seed 에서 CI 0 미만)**: 크기 방향 소거가 같은 norm 의 무작위 방향보다 *덜* 해롭다. 후보 설명(모두 추정): (a) 크기 방향 변위는 최소 변경이며 데이터 분포의 주요 분산 방향 안이라, predictor 가 분포 안 입력으로 처리한다. 등방 무작위 방향은 분포 밖이라 같은 norm 에서도 더 큰 교란이다(README 한계 항목이 같은 취지의 반대 방향 우려를 적었다: "모델이 민감한 방향이 아닐 수 있다"가 아니라 여기서는 오히려 무작위가 더 해롭다). (b) motion 지표가 `pred - z_e` 를 쓰므로 입력 복사 성분이 변위 크기에 비례해 잔차에 섞인다. 같은 단위에서 total 지표의 Δ_use 가 +0.481 로 부호가 반대다. 지표 선택이 결론을 뒤집으므로 "사용 안 함"과 "사용함" 어느 쪽도 이 한 지표로 단정할 수 없다. 이 부호 반전은 판정 기준에서 사전에 정한 (B) 가 아닌 (A)를 본 것이므로 탐색적 관찰이다.
- **random-init 기준선이 약 0 이 아님(-0.68 / -0.18)**: 가설의 사전 예상과 어긋났다. 학습 안 된 predictor 는 입력 크기 변위에 대해 큰 비선형 교란 응답을 하며, 크기 방향이 무작위보다 덜 해롭다는 패턴이 (b) 학습 모델과 같은 부호다. 즉 학습된 모델의 음수 Δ_use 는 "학습으로 생긴 크기 불사용"이라기보다 소거 방향 대 무작위 방향의 기하 차이일 가능성이 크다(추정). random-init 의 Δ_use 가 학습 모델보다 더 음수라는 점(-0.68 대 -0.15)은 학습이 이 차이를 줄였다는 읽기도 가능하나(추정), 정규화 분모가 다르므로 직접 비교는 어렵다.
- **level_mean_match 의 작은 양의 Δ_use(약 0.02) 와 cond3 충족**: cond1(seed 3/3)과 cond3 이 맞았지만 크기가 gap 의 약 3.5% 라 사전 기준(10%)에 크게 못 미친다. (b) > (a) 는 방향 면에서 "다중 크기 학습이 크기 의존 사용을 만든다"는 가설과 합치하지만, (a) 도 -0.025 이고 차이 0.045 의 불확실성은 seed 3 개 사이 분산으로 판단해야 한다(seed 별 (a) 값은 직접 확인하지 않음, 미확인). 해석은 "방향이 가설과 같고 크기가 작다" 이상 불가.
- **0단계 관문**: 통과했으나 비 1.04-1.46 으로 약하고, 패치 평균 ridge 회귀기의 도구 한계가 크다. 크기별 동역학 차이가 있다는 증거로는 약하며, 있다면 매우 작은 것으로 읽힌다. 따라서 "크기를 쓰는 것이 이득인 정도 자체"가 작을 수 있어, 사용 검출 실패는 *사용할 유인이 약하다*와 구분되지 않는다(추정).
- **2단계 (a) 상관 -0.03~-0.05 대 (b) 0.46~0.56**: 상관이고 판정에 쓰지 않기로 했다. 그래도 (b) 만 레벨 평균 Δz 의 레벨 간 차이를 어느 정도 따라간다는 점은 크기 의존 예측이 학습으로 생길 수 있다는 방향의 약한 증거다. 다만 (b) 는 학습 레벨(a060, ind, a160)이 있고 이 상관은 9레벨 전체(OoD 6개 포함)에서 계산돼 외삽 레벨이 섞여 있다(추정). 소거 개입 결과(Δ_use 는 작음)와의 불일치는 "예측은 크기 의존적이지만 이 입력 소거로는 그 경로가 끊기지 않는다"로 정리 가능(추정). 이는 소거 확인 R² 가 블록 1 에서 회복한 것과 일관된다.
- **인코더 일치 점검**: `first_batch_max_abs_diff_encoder_vs_cache` 가 0.0990 으로 모든 단위에서 같다. `encoder_matches_cache` 는 true 지만 최대 절대 차이 0.099 가 의미하는 바(정밀도 vs 전처리 차이)는 내가 확인하지 못했다(미확인). 소거기 적합이 캐시 latent, 평가가 재인코딩 latent 라 소량의 분포 어긋남이 소거 잔여를 키울 수 있다(추정).

## 4. 빠진 baseline / 대조 / 인용
1. **학습된 모델의 전체 입력 노이즈 내성 대조**: 크기 무관한 일반 교란(데이터 분산 방향 안의 무작위 변위, 예: 다른 episode 의 패치 평균 차이를 더하기)을 무작위 방향 대조에 추가. 등방 가우시안은 분포 밖이라 대조가 너무 강하다(3절). 이것이 없어서 음수 Δ_use 의 의미가 불분명하다.
2. **교체(interchange) 대조**: 크기 정보만 다른 레벨의 평균으로 *교체*(패치 위치별 레벨 평균을 다른 레벨의 것으로)하고 예측 Δz 가 그 레벨 쪽으로 이동하는지. level_mean_match 는 평균을 전체 평균으로 모으는 소거인데 교체 방향(a060 입력에 a160 평균을 넣기)은 causal abstraction 식 검사에 가깝다. 짝 episode 없이도 가능하다(레벨 평균 이동이므로).
3. **블록별 소거(깊이 이동)**: 입력 한 점에서만 소거하면 블록 1 에서 회복되므로(R² 0.68-0.72), 각 블록 입력에서 매번 소거(009 의 intervene 와 같은 반복)한 변형. 이 없이는 "사용 안 함"과 "회복되어 사용"을 구분 못한다.
4. **GT 최적 하한/상한**: 크기 레이블을 아는 oracle predictor(크기를 입력으로 주는 모델)와 크기를 모르는 평균 predictor 의 motion 오차 차이. 0단계 관문의 ridge 비가 이 역할을 거칠게 하지만 predictor 급은 아니다.
5. **그림이 아닌 지표 부호 점검**: motion 과 total 의 부호 불일치(3절)를 시각적으로 점검할 수 있게, 같은 소거 입력에서 예측이 입력 복사에 얼마나 가까운지(`pred - z_e` 의 norm)를 보고. `copy` 는 저장돼 있으나 pred 와 z_e 거리 자체는 확인하지 못함(미확인).
6. 인용 필요(원문 확인 후): Elazar 2021 amnesic probing, Belrose 2023 LEACE, Ravfogel 2020 INLP, Kumar 2022, Geiger 2021 causal abstraction(전체 [미확인]), Hewitt & Liang 2019, DINO-WM(Zhou et al.).

## 5. 후보 가설 (검증은 사람 승인 후)
- H1: 크기 정보 사용 경로는 입력 한 점의 소거로 끊기지 않고 첫 블록에서 재구성된다. 블록마다 반복 소거하면 (b) 의 Δ_use 가 cond2 문턱(gap 의 10%) 이상으로 커지고 (a) 와의 차이도 커진다.
- H2: 음수 Δ_use 는 소거 방향의 기하(데이터 내부, 최소 변경)와 무작위 방향의 기하(분포 밖) 차이다. 데이터 분산에 비례하게 뽑은 무작위 변위 대조로 바꾸면 LEACE 의 Δ_use 가 0 쪽으로 이동한다.
- H3: 레벨 평균 교체(a060 입력에 a160 평균)는 (b) 에서 예측 Δz 를 교체 레벨 방향으로 이동시키고 (a) 에서는 이동시키지 않는다(상관 0.46~0.56 대 -0.03~-0.05 의 인과 판).
- H4: random-init 의 큰 음수 Δ_use 는 predictor 의 입력 민감도 때문이며 학습으로 줄어든 것이다. 정규화 분모를 맞춘(예: persistence 대신 동일 입력 복사 오차 기준) 지표로 보면 학습된 모델과 random-init 의 차이를 직접 비교할 수 있다.

## 6. 확신도
- **중간(낮음에 가까운 부분 포함)**. 근거: (높음) 판정 라벨, Δ_use 수치, 0단계 비, 2단계 상관, random-init 기준선은 results.json 에서 직접 읽었다. (중간) 지표 부호 반전(total 대 motion)은 한 단위(single_ind seed 0 LEACE train)만 직접 확인했고, 소거 확인 R² 는 log 요약을 인용했다(원본 `erasure_check_readout_r2` 의 split 별 전체는 읽지 않음). (낮음) 3절 설명들(기하 차이, 지표 인공물, 인코더 0.099 차이의 영향)은 전부 추정이며 검증 실험이 없다. 문헌 서술은 대부분 초록 수준 또는 기억 기반이라 정량 비교 근거가 없다(Causal abstraction, DINO-WM 관련은 미확인). results.json 이 720 KB 라 전수 검토하지 못했다.
